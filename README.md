# 个人专属App

个人自用、只在本机浏览器本地运行的日常管理工具。数据保存在本机磁盘，关机/重启不丢失；无需登录、联网、云数据库、部署和手机端。

## 快速开始
1. 双击项目根目录的 **`启动.bat`**。
2. 它会自动启动本地服务并打开浏览器（`http://localhost:3000`）。
3. 如需停止服务：在最小化的命令行窗口按 `Ctrl+C`。

## 功能模块
| 模块 | 说明 |
|---|---|
| 首页总览 | 今日完成度、快捷备忘、各模块摘要卡片、到期日程高亮提醒 |
| 今日计划 | 每日任务增删改、勾选、优先级排序、完成率 |
| 运动健身 | 训练记录、身体指标趋势、目标进度、本周/本月统计 |
| 读书学习 | 书单、读书笔记、专注计时、统计 |
| 业务开展 | 客户管理、订单销售、款项台账（应收/实收/未收）、销售统计 |
| 日程提醒 | 月历视图、当日日程、到期页面内提醒 |
| 数据设置 | 导出备份、导入恢复、数据统计、提醒开关、清空数据（二次确认） |

## 数据安全
- 数据落盘：`data/appdata.json`（本机磁盘，关机重启保留）。
- 原子写入：先写临时文件再改名，防断电/崩溃损坏。
- 备份：在「数据设置」导出为本地 JSON 文件；导入可恢复。
- 损坏兜底：数据文件损坏时自动保留现场为 `.corrupt.*` 文件，并返回空数据。

## 运行环境
- 仅依赖 **Node.js**（本机需已安装，v18+ 即可），零第三方 npm 依赖。
- 端口：默认 `3000`；如被占用可设置环境变量 `PORT` 指定其他端口。

## 运行测试
```bash
npm test
```
或
```bash
node --test "tests/*.test.js"
```
覆盖：数据层原子写/校验/损坏兜底、API（保存/导出/导入/重启保留）、前端纯逻辑（统计/到期/排序）、静态资源安全（防目录穿越）。

## 技术形态
- 服务端：Node 原生 `http` 模块（`server.js`）
- 数据层：`data-store.js`（原子写盘 + 校验 + 损坏兜底）
- 前端：`public/`（单页应用，hash 路由；`core.js` 为可测纯逻辑）

## 已知边界（第一版）
- 提醒为**页面内提醒**：仅在浏览器打开时生效；系统级桌面通知留作后续升级。
- 单人单机使用，无多用户、云同步与手机端。
